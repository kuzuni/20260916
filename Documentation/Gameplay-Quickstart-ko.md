# 게임 업데이트 확인 안내

- 새 저장은 스테이지 1, 대장간 1레벨, 망치 1,000개로 시작합니다. 진행 상황은 로컬에 저장됩니다.
- 모루를 누르면 망치를 쓰고 1초 동안 망치 3타와 타격 불꽃 → 정사각형 등급 프레임 안에 장비를 0.5초 공개 → 비교창 순서로 진행합니다. 이미 낀 장비가 있으면 장착 버튼으로 두 장비를 바꿔 비교하고 판매로 선택을 확정합니다. New 표시는 장착 위치를 바꿔도 새로 뽑은 장비를 따라갑니다.
- 대장간 레벨 버튼에서 골드 게이지를 채우고 시간 업그레이드를 시작합니다. 시간이 지나도 완료 버튼을 직접 눌러야 레벨이 오릅니다.
- 자동 제련에서 유지 등급, 추가 옵션, 배치 크기를 설정합니다. 한 번에 쓸 망치 수는 드롭다운에서 1~99개 중 고르며, 설정은 다시 열어도 유지됩니다. 계속하기를 켜면 목표 장비를 설정한 배치 크기만큼 모은 배치가 끝난 뒤 비교합니다. 예를 들어 22개씩 제련하여 10개, 11개, 5개가 나오면 26개를 보관한 뒤 비교합니다. 제련 도중 종료해도 재접속 시 자동판매와 보관을 이어서 정산합니다.
- 장비 기본 수치는 선형으로 증가합니다. 체력 장비 한 부위 기준 원시 1레벨은 80, 원시 100레벨은 880, 중세 1레벨은 1,760입니다. 공격 장비는 같은 비율로 10 → 110 → 220이 됩니다.
- 스킬 탭에는 원시부터 천상까지 등급당 3개씩, 총 30개 스킬이 있습니다. 보유한 항목만 한 줄에 3개씩 크게 표시합니다. 상세창의 **스킬 연출 보기**를 누르면 소유 여부와 무관하게 해당 연출을 확인할 수 있습니다. 원시의 사냥꾼의 만찬·돌팔매·태고의 거석, 현대의 전차 돌격·고폭탄 투하, 천상의 신의 축복·신의 분노 등이 포함됩니다.
- 약공격은 기존 총 고정 피해를 3타로 나누고, 강공격은 기존 총 피해를 20% 낮춰 5타로 나눕니다. 각 스킬마다 준비·궤적·타격 간격·마무리가 다르며, 곡선 궤적은 빠른 상승·정점의 멈칫·빠른 낙하로 표현합니다. 발동 주기는 약공격 2턴, 강공격 5턴을 유지합니다.
- 스킬·펫·탈것은 같은 항목이 한 카드로 모이고, 조각을 써도 해금은 유지됩니다. **모두 업그레이드**는 각 항목의 조각으로 가능한 최대 레벨까지 반복 강화합니다. 항목 레벨의 상한은 100입니다. 소환권을 먼저 쓰고 부족한 수만큼 1회당 다이아 100개를 씁니다. 소환 버튼에는 실제로 쓰는 재화의 아이콘과 수량만 나오며, 혼합 결제일 때 두 재화 사이에 +가 표시됩니다. 펫 소환 재화는 알 자체, 탈것 소환 재화는 말발굽 자체의 아이콘입니다.
- 소환 결과는 카드가 차례로 나타납니다. 공개 도중 한 번 탭하면 남은 결과가 모두 나타나고, 공개가 끝난 상태에서 다시 탭하면 닫힙니다. 목록을 스크롤하는 드래그는 닫기 탭으로 처리하지 않습니다. 확률 창 아래에서는 선택한 카테고리의 현재 소환 경험치를 확인할 수 있습니다. 필요 경험치는 최대 100이며, 소환 레벨도 100에서 멈춥니다. 이때 확률 창의 경험치 대신 **승천하기**가 나타납니다. 종류별로 3회까지 승천하며 해당 종류의 보유·장착·조각을 초기화하고 새로 수집합니다.
- 오프라인 보상은 접속 여부와 무관하게 골드 초당 1개, 망치 분당 1개를 모읍니다. 최소 1분이 쌓여야 수집할 수 있으며, 수집 후 남은 초는 유지됩니다.
- 진행 패스는 최고 클리어 스테이지를 기준으로 5스테이지마다 한 번씩, 500까지 보상을 줍니다. 열면 처음 받을 수 있는 보상으로 이동하며, 받을 것이 없으면 다음 목표 구간을 보여줍니다. 가운데 청록색 세로 게이지는 클리어 진행도만큼 채워지고 중간 다이아 장식은 표시하지 않습니다.
- 던전 열쇠와 대장간 무료 스킵은 한국 시간 자정 기준입니다. 열쇠는 보유량이 2개보다 적을 때만 2개로 보충됩니다.
- 던전은 열쇠가 있어야 입장할 수 있지만, 입장·패배·취소에서는 열쇠가 줄지 않습니다. 승리 후 보상 팝업에서 **보상 수령**을 눌러야 열쇠 1개가 소모되고 보상과 클리어 기록이 반영됩니다. 미수령 보상은 저장되며, 받기 전에는 새 입장과 소탕을 할 수 없습니다. 소탕은 누르는 즉시 열쇠 1개를 써서 이전 난이도의 보상을 받습니다.
- 아레나는 더미 상대와 전투하며 종료할 때마다 보상이 지급됩니다. 도전 기회는 한국 시간 자정마다 5회로 충전됩니다. 상점 버튼은 실제 결제 없이 표시된 상품을 로컬로 지급합니다. 다이아 상품은 3열·2행으로, 첫 줄은 **무료 다이아 100 / 600 / 2,200**, 둘째 줄은 **8,000 / 15,000 / 33,000**입니다. 무료 상품은 한국 시간 기준 하루 한 번 받을 수 있습니다.
- 원시 펫 3종(원시 꼬마·검치호 새끼·새끼 익룡), 원시 탈것 3종(원시 랩터·야생 멧돼지·돌바퀴 수레)의 그림과 분리 부위 리그 소스가 추가되었습니다. 상위 시대 펫·탈것 그림과 엠블렘·날개·정령 기능은 보류 상태입니다. 30개 시대별 스킬 그림과 연출, 알·말발굽 재화 그림은 유지됩니다.

- 대장간 35레벨에서 골드·시간 업그레이드를 모두 마치면 승천할 수 있습니다. 최대 3회이며 대장간은 1레벨, 장비·뽑기 카운트는 초기화됩니다. 장비와 컬렉션 모두 다음 승천 원시 1레벨이 이전 승천 천상 100레벨의 두 배가 됩니다. 승천 횟수만큼 별이 표시되고 0회에는 숨겨집니다.
- 소환 수량은 ×1·×5·×10·×20·×50·×100·×500입니다. 100레벨까지 남은 수량보다 많이 선택하면 확인 팝업이 뜨고, 확인한 남은 수량만 소환하고 소모합니다. 큰 결과 목록은 스크롤할 수 있습니다.
- 메인 대장간 버튼 아래에 시간 업그레이드의 남은 시간과 완료 상태가 표시됩니다. 빨간 알림은 해당 보상·입장·소환·업그레이드·빠른 장착이 가능한 조건에서만 나타나며 크기가 반복해서 변합니다.
- 같은 스테이지의 다음 웨이브에서는 플레이어와 남은 체력·전투 상태가 이어지고 다음 적이 입장합니다. 새 스테이지에서는 새 전투를 시작합니다.
- 전투는 머리 위 월드 HP와 피해 숫자를 사용합니다. 일반 피해는 흰색, 치명타는 빨간색, 회복은 초록색입니다. 웨이브가 진행되면 상단 연결선이 차고 다음 노드가 커졌다 돌아옵니다. 발밑 HUD에서 장착한 스킬과 남은 턴을 확인합니다. 장착 스킬 슬롯과 보상·패스 아이콘은 이전보다 1.5배 커졌으며, 보상·패스 글자 크기는 서로 같습니다.
- 실제 전투력이 바뀌면 새 총 전투력 위에 증가 시 초록색 UP 화살표, 감소 시 빨간색 DOWN 화살표가 나타났다가 사라집니다. 처음 불러오거나 값이 그대로인 화면 갱신에는 표시하지 않습니다.

장비 기본값을 조정할 때는 EquipmentRules의 공통 수식을 변경하면 스킬·펫·탈것의 기준 능력치도 함께 바뀝니다. 상세 규칙과 임시 밸런스 값은 [게임 규칙](Gameplay-20260918.md)을 참고하세요.

원시 동료 리그는 10가지 체형 템플릿 중 6종 샘플을 사용합니다. 샘플마다 8개 분리 부위에 실제 SpriteSkin과 뼈를 적용하고 Idle·Walk·Attack·Hit·Death 애니메이션을 생성하도록 구성했습니다. 통이미지 한 장을 흔드는 방식이 아닙니다. 생성된 프리팹 6개·부위 스프라이트 48개·클립 30개·컨트롤러와 카탈로그를 PR94로 반영했습니다. 클라우드 run109의 210개 테스트에서 실제 부위 변형과 탑승 연결을 확인했습니다. 최종 조립 모습과 최신 소스의 화면 검증은 별도로 진행 중입니다.

Unity 실행 검증은 클라우드에서 수행합니다. 테스트 결과와 실제 화면 캡처는 별도 검증 보고서에 기록합니다.

최신 사용자 지시에 따라 리깅 작업은 현재 상태로 중단했습니다. 연결부가 벌어지는 등 알려진 조립 외형 문제는 그대로 남아 있으며, 리그 수정·재생성은 진행하지 않습니다. 스킬 연출과 일반 UI 수정은 계속합니다.
