## 이후 진행

예약 작업은 검토 가능한 수정 묶음마다 미리보기 폴더를 갱신합니다. 사용자가 수정한 파일이 발견되면 덮어쓰지 않고 갱신을 보류합니다. 화면 묶음을 독립적으로 검증할 수 있게 나누고, 해당 묶음의 코드·클라우드 CI·화면 검수가 끝나면 main에 순차 반영합니다. 미리보기 상태와 main 완료 상태를 구분해 보고합니다.

에이전트는 로컬 Unity 에디터를 실행하거나 조작하지 않습니다. 자동 실행 검증은 GitHub-hosted CI에서 합니다.
